## 📖 My NUR-Repository
> This is my `nur-packages` repository.
> Status: beta: Already supported **Flakes**. Added `go-hello-world` package writеут on `go` by bluecodemonks.

## How to use 💻:

### 1. Clone the Repo:

```bash
git clone "https://github.com/Esmegayt/nur-packages"
cd nur-packages
```

### 2. Build a package that you need (example):

```bash
nix-build -A go-hello-world
```

### 3. Enter the environment:

```bash
nix develop
```
